# 龙族 · 执行员登录主题

把 DeepSeek Harness 装扮成《龙族》里卡塞尔学院执行部的终端：打开即执行权限确认，随后以“专员”身份致意，进入后的界面换成黑金执行部配色与全屏 HUD 描边。

## 功能

- **权限确认动画**：打开应用（新标签页会话首次加载）时全屏播放。依次校验“执行员信标 — 生物特征 — 言灵权限 — 龙文密钥 — 权限等级”，进度条走满后进入欢迎阶段。开场 1.2s 后可 `Esc` 或点击任意处跳过。
- **欢迎语**：以打字机效果显示“欢迎您，<专员代号> 专员”，并给出权限等级 S 的登录完成提示，随后淡出。
- **黑金皮肤**：以主题令牌覆盖层（`--dsw-alias-*` 等）叠在系统主题之上，因此跟随「设置 → 外观」的浅色/深色；深色为墨黑 + 青铜金，浅色为羊皮纸 + 墨金。可在“执行员档案”里一键开关。
- **全屏 HUD**：四角描边、网格、扫描线与缓慢下移的扫描光带，透明度很低、不接收指针事件，也不含任何文字，不遮挡应用控件。
- **侧栏品牌**：品牌位换成龙纹徽记，品牌名换成 `CASSELL 执行部`（以更低优先级的槽位注册覆盖官方品牌位）。
- **执行员档案（设置 → 执行员档案）**：修改专员代号、开关配色/HUD/开场动画、重播权限确认。

## 使用

1. 安装插件后打开（或刷新）页面，权限确认序列会自动播放一次。
2. 想改代号：设置 → **执行员档案** → 修改“专员代号” → 保存档案，再点“重播权限确认”即可看到新欢迎语。
3. 不想每次看到开场：在同一页点“关闭开场动画”。

## 已知边界

- 欢迎语只在**当前标签页会话**首次加载时自动播放；同一标签页内刷新不再重播，避免打扰。想再看就用“重播权限确认”（该按钮会先关闭设置面板再播放）。
- 专员代号默认是占位名「无名」，请在“执行员档案”里改成你自己的代号；改过之后会存在本机浏览器里，刷新与重开都保留。
- 配色只覆盖 alias 令牌与少数内部令牌（主按钮悬停、选中边框、焦点环）；宿主组件里硬编码颜色的局部不会被改写。
- HUD 与门禁动画只注册在 `shell.overlay` 槽位内，不替换应用根节点，也不读写其它插件的 DOM。
